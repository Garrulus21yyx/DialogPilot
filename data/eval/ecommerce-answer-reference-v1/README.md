后续只测当前方案时，每题生成一次实际答案即可，不必跑旧方案。系统生成时仅提供问题/历史和当前检索证据，不提供本参考答案；评分时另行使用本稿。允许等义表述，不能按字符串相等或现有verifier PASS直接计答案正确率。两方案配对是证明收益时才需要，不是每份答案都要生成两次。
