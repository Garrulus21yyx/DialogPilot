# 复杂电商纯RAG模拟集 v2

120题/30规则族；按族划分40开发（10族）与80留存（20族）。每族四种提问体裁：直接询问、多轮确认/纠正、假设、前提未确认。体裁模板跨集合共享，产品主题部分沿用v1；不冒称真实客户数据、人工gold或未见主题泛化。

每题要求跨三份Markdown手册找到基础条件、限制/例外、步骤/费用三处条款。每处保存原文quote与半开字符区间，全部三处覆盖才计完整证据成功。三份另渠道/旧版资料作干扰。每份约1405—2897字符，多章节/小表格，属于中等长度文本，不是长PDF/复杂合并单元格文档。

`rules.json`为作者规则；`corpus.json`为六份完整文档；`*.inputs.json`仅问题和角色历史；`*.gold.json`包含证据标注，运行模型不读取。`manifest.json`锁定hash。语义标注未获独立人工审定；字符检查不证明标签业务语义完备。

当前结构切块512/64得到17片段，所以候选R@20接近全库覆盖，不能用于证明大规模召回效果；本版本主要区分多证据Top5排序与打包。日期/渠道区别写在文档中，不是实际source生命周期、metadata硬过滤的验收。
