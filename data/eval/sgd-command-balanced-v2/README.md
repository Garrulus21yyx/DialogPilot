# DialogPilot SGD Command adapted benchmark

This is an adapted, deterministic subset of the Schema-Guided Dialogue dataset. Source annotations are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The upstream repository and pinned commit are recorded in `manifest.json`.

Scores from this artifact measure DialogPilot Command IR adaptation; they are not official SGD leaderboard scores and are not production traffic accuracy.
