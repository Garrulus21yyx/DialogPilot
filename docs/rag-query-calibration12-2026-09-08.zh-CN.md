# 真实 Agent 查询与证据交付：12条开发校准

2026-09-08。**开发候选出现可测收益，但未采用到生产；三套最终验收和简历终值尚未完成。** 本次没有把单路检索成绩当成 Agent 答案准确率。

## 固定条件与入口

Doc2Dial 已暴露开发集，按冻结数据顺序选前12个有历史的独立conversation。顺序选择导致本批集中在DMV，不代表三类领域或真实电商流量。语料仍为原开发100篇完整文档，无gold-only缩库。历史角色与原文从官方archive复验。

真实 `ConversationAgent.plan` 接收原始多轮消息和政府服务领域registry；输出通过现有编译器成为查询。未强制知识goal，未用手工完整query代替Agent。没有查询、协议失败、澄清都保留；只对单条实际knowledge query做后端重放，未采用隐式raw回退。本批没有委派分支，不把潜在领域Agent查询算成失败。

固定结构切块512/64、缓存BGE文档向量、两路各20、RRF k10与.5/.5、融合20、本地BGE cross-encoder、最终5片段/2600tokens。使用生产ContextPacker和知识工具模型可见序列化，复验原文偏移及checksum。检索后端为本地参考重放，**不是PostgreSQL端到端或最终答案评测**。不重新向量化文档。

两臂Flash NONE，每题一次，共24调用，无SDK重试。每次运行前写样本、源码hash和预算；基线/候选实际payload、输出Schema、模型相同，raw检索结果逐例相同。候选只在实验子类中增加通用决策说明：补答继续原信息需求；缺政策证据先查询一般规则；个体适用信息缺失不自动阻止检索；直接回复不代替待查证政策。未修改生产prompt。

## 配对结果

下列指标统一以12条为分母；未查到证据计零证据交付，不自动判定澄清或最终答案错误。

| 指标 | 当前Agent | 开发候选 |
|---|---:|---:|
| 实际生成单条知识查询 | 1/12 | 6/12 |
| 完整候选证据交付 | 1/12 | 6/12 |
| 最终工具可见完整证据 | 1/12（8.3%） | 6/12（50.0%） |
| 工具可见MRR@5 | 0.0833 | 0.4583 |
| 工具可见nDCG@5 | 0.0833 | 0.4692 |
| 输出协议失败 | 0/12 | 1/12 |

完整可见证据**救回5、误伤0**。候选剩余5条RESPOND与1条INVALID_PROVIDER_OUTPUT，不能删除后声称100%成功。

另外，对12条原始短query强行跑后端的诊断得到4/12完整可见证据；它不是旧Agent基线，不能与真实Agent混称一次架构前后对照。此前300条开发集66.3%→69.3%属于不同入口与范围，也不能与此处8.3%→50.0%拼接成66%→79%。

## 失败含义与采用门槛

- 模糊投诉问题继续澄清合理；不检索不必然错。
- 两条纽约外州检验问题由仅回复转为实际检索；原回复存在说要查却未查、未经依据说明政策的情况。
- 检验延期补答仍重复询问问题类型；假设额外明确日期/车型才能检索未被证明。
- 私人卖家检验问题部分仍要求地区/检验种类，是否确需澄清要独立语义复核，不能为了高分强制检索。
- `do not`仍被解释为不愿继续；原文有歧义，保留而不新增关键词补丁。
- 一题候选结构化工具参数为空，生产合同正确拒绝；未重试刷掉失败。
- 问罚款、未过期贴纸更换、检查项目等问题从直接回复变为有原文依据的检索。

这是作者开发复核，不是独立盲评。候选不满足生产采用与泛化验收：仍需冻结respond/取证决策合同，补非知识对话、合理澄清、多轮补答的代表性验证，以及未使用的分组验收。当前不扩大付费批量、不改变切块/权重、不启动微调。

**简历暂不新增本批终值。** 本批的可信结论是定位并改善了Agent入口的漏查，而非已经获得三套最终验收成绩。
