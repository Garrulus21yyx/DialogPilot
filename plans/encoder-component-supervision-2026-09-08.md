# Encoder 成分监督收敛实验

状态：实现及开发实验完成，采用失败；HEAD 起点 4f6f87b。Encoder 可用性未关闭。

## 根因与边界

已有分类与完整性配对监督均把多目标、否定、换对象、信息不足折叠成 DEFER。
下游只能执行一个目标；相关主题被接受不等于完整请求被覆盖。
已检查训练构造器：`no` 数组同时包含取消、修正和肯定后追加目标，不能将所有
DEFER 反标成“三个意图均不存在”。本次修复的 owner 是离线监督及评分转换，
不在 Router、Registry 或业务工具中增加关键词分支。

正向合同：一个上下文模型同时预测三个能力是否被请求、是否被否定，以及是否需要
进一步规划。未知成分不当负例；只有唯一请求、没有对应否定、没有规划阻塞才成为
现有 FastPathPolicy 的候选。权限、参数来源、状态绑定仍由原控制面决定。
否定辅助监督与历史角色一起输入，不使用运行时句法拆分器或额外 LLM。

## 预注册实验

- gap: ENC-COMPONENT-SUPERVISION；假设：显式成分监督减少遗漏附加目标及否定误接收。
- 数据：沿用 semantic-encoder-v2-final 的源数据与拆分；由已记录构造来源恢复确定标签，
  其余未知用 mask，不能凭 DEFER 猜测语义。新增组合按源 split 隔离。
- 固定：两种语言分开；原 BGE-small backbone/revision、seed 17、4 epochs、lr 3e-5。
- 预算：每语言一次 GPU 拟合；不调用业务写操作或 τ³，不新增线上模型调用。
- 指标：逐语言/范围 accepted precision、coverage、错误接受 DEFER、上下文正确接受、
  成分预测完整性、GPU batch-1 P95；记录样本族相关性，不宣称真实线上风险保证。
- 采用：开发与新留出 accepted precision >= .98，DEFER 错接收为 0；上下文正确接受
  优于 char baseline，总正确接受不减少，GPU P95 <= 100ms。失败保留，不调参后重称 fresh。
- 回归：whole-request 160、此前 semantic 120、原独立 50；全部明确为已消费。
- 非目标：重写在线 Agent、RAG、审批、引入第二条在线执行路径、解决无限类别。
- 独立审查：依据 AGENTS 重复重开协议，请原独立审查 Agent 检查数据合同与最终证据。
